# Forka careers page - apply.forka.com

Public page where job applicants see open Forka jobs (English / Arabic) and apply with their CV. No account needed.

- `index.html` - the page (same as erp.forka.com/apply in the forka-erp repo; tests live there).
- `config.js` - the Forka Hiring server address. No secrets.
- `CNAME` - tells GitHub Pages this site is apply.forka.com.

Applications go to the "Forka Hiring" Google Sheet and appear in Hiring at erp.forka.com/hiring.
